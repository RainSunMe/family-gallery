# Screenshots

Images in this directory are used by the README. They show the app running with
sample data only — no personal photos.

| File | Page |
| --- | --- |
| `01-albums.png` | Album list, the landing page after sign-in |
| `02-photos.png` | Photo grid inside an album, with the uploader's name on each tile |
| `03-viewer.png` | Full-screen viewer with the photo info panel |
| `04-share.png` | Read-only share link and QR code |
| `05-invite.png` | Invite page a guest sees when a family member asks for photos |
| `06-login.png` | Sign-in screen |

To regenerate, run the app with throwaway data and capture at 1600×1000 (desktop)
or 390×844 (mobile). Keep files under ~400 KB each; PNG for UI, and crop away any
real names, dates or locations.
