# Screenshots

Images in this directory are used by the README. They show the app running with
sample data only — no personal photos.

| File | Page |
| --- | --- |
| `01-albums.jpg` | Album list, the landing page after sign-in |
| `02-photos.jpg` | All photos, with the uploader's name on each tile |
| `03-viewer.jpg` | Full-screen viewer with the photo info panel |
| `05-invite.jpg` | Invite page a guest sees when a family member asks for photos |
| `06-login.jpg` | Sign-in screen |

To regenerate, run the app with throwaway data and capture at 1600×1000, English
locale, light theme (the viewer is dark by design). Export as JPEG at quality 88–90;
all five files together should stay under ~700 KB. Crop away empty margins on
narrow pages, and make sure no real names, dates or locations are visible.
